# 2026 半年年度总结

## 前言

2026 年过去一半，在这里简单记录一下这半年的变化、收获和一些随想。

## 回顾

第一个季度：
把之前开发的 APP，上架 IOS 和 Google 应用商店：这个工作其实没什么难度，主要就是账号申请流程麻烦，另外这一块我有经验，所以毫无压力，很快就搞定了。

从 0 到 1 构建一个有竞争力的精准农业 Web 系统，让用户得倒丝滑的和良好的体验：这个从 0 到 1 全是我一个人用 AI 工具做出来的，比较费时间的是业务版图的梳理和 UI 设计的确认，当前 UI 也是用 AI 工具生成的，前前后后我尝试了好几个工具，最终才给了我觉得完美，产品觉得不错的 UI 设计，后面确定设计之后，确定了基础框架和基础组件，让 Cursor 按照既定的规则开始开发代码，所以整体的话难度也不是很高，毕竟前端这块技术已经没有太大的瓶颈了，但是 Cursor 足够了，就这样，部门里面的第一个 Vibe coding 项目成功上线了，而且得到了国际客户的一致好评，比之前老版本的系统体验更加丝滑，界面更加美观，完全摒弃了之前所有的设计，大胆开发，大胆设计，做就完了！

大数据地图渲染：这个其实我刚进这家公司就在调研的方案，在精准农业的版图里面，大数据的地图渲染师非常重要的一块，需要渲染大量的轨迹和数据来对作业的数据进行分析，纯纯前端的方案已经不够用了，在这个期间尝试使用了 geoserver 这个中间件来做核心图层的方案，包括数据存储，图层设计等都是自己独立完成的，现在的效果只能说够用，如果要达到业界先进水平还有一些差距，因为精准农业的作业情况非常复杂，轨迹的方式也会比较多样，多 Boom, 多 Chanel 如何展示，以及分段和位置如何展示到现在也是我们一直在攻克的问题，因为这个数据格式很复杂，涉及角度，幅宽等在 WEB 端的绘制。

APP 健康监控：为了达到目的，也没必要自研，直接在公司部署了一套 Sentry，贼好用，其他团队都开始使用它。

第二个季度：
精准农业核心功能的构建：农机配置互通、路径线下发、全域路径规划、田块任务数据分析。这些就是常规的产品需求和业务开发，自己从 0 到 1 端到端闭环，从设计到前后端开发到上线，现在唯一不能自己闭环的就是测试，因为虽然现在测试也可以自动化，但是 Web 端自动化测试比较耗费 tooken, 所以现在还是比较依赖测试人员测试，而且开发人和测试人的思维还是有一些不一样，开发人能做到逻辑闭环，也能写让 AI 写单元测试来闭环流程，严格按照 TDD 开发的流程来做，只能说没有什么大的问题，但是有的时候还是有一些异常场景没法闭环，端到端闭环还有一点点差距，但是我感觉这个会很快了，现在已经有些所谓的 AI Native 组织其实已经做到这一点了。

前端工程师转型全栈开发：后端框架，基础配置，Vibe coding 开发后端所有的接口，闭环端到端的核心功能。有了 AI 工具之后，职位之间的职责开始变得模糊起来，现在企业的要求变高了，成本控制也非常严格，所以如果再像之前一样只做自己那一块特有的工作的话，可能很快就会被淘汰掉，所以也只能转型了。

## 随想

这半年给我的感觉就是企业对人的要求变高了，之前可能是需要 **T 型人才**：知识广度 + 专业深度；现在可能是需要所谓的 **E 型人才**：AI 能力 + 品味 + 架构能力 + 续航能力。

回想上半年工作上的情况感觉就是我一个人扛起了整个业务的大部分板块，成为了这个业务的研发负责人。业务板块丢给你了，你只需要想尽一切办法完成就是了，如果过程中有阻塞有瓶颈，能自己解决的就自己解决，自己不能解决的就拉资源解决，反正最后成功达成目的就行，不管你用什么方式，上面的人只看结果。

进入这个家公司是以前端 SE 的角色进来的，随着 AI 的发展，发现只做前端相关的工作已经混不开了，所以现在就是前后端都做，好在现在很多编码工作已经不需要人去完成了，只要你能做架构设计，深刻理解业务，你就可以做很多之前你无法完成的工作，主动性和能动性变得更加重要，这种情况下单兵极限作战的能力可以一下凸显出来。

现在做的这个业务方向是精准农业的方向，这个在之前我是从来没有接触过的，所以在这一家公司我学习和收集了非常多精准农业相关的解决方案。发现这个行业涉及的东西其实非常广泛，地理，遥感，数据，硬件，软件，算法、大数据，有的时候做一个功能，牵扯的上下游可能会非常多，所以在这半年也是一直在变做边学习的阶段。精准农业我现在粗浅的理解就是通过各种数据的来源和整合，精确的分析出农作物 耕、种、管、收四个大的阶段的策略和相关的动作，然后可以在各个阶段精细化的管理作物，然后做相关的动作，最后对已经实施的措施进行效果数据分析，得到一个来年的规划和措施，当然如果是大型的农场，还需要更加精细的管控每种作物，每个田块的几大阶段的时间，管控物料，管控人员，管控成本、管控收益，管控一切跟钱挂钩的事物，最后把这些数据都可视化的展示出来，分析出来，形成一套精细化运作的系统来应对每个季节的变化。这里面每个阶段都有非常多的玩法，也产生了非常多的上下游的服务。有专门做处方图的，有专门做路径规划的，有专门做农机管理的、有专门做任务分析的，还有专门做遥感数据的，非常多的服务厂商，这个赛道非常卷，可能现在就没有不倦的吧。

这半年听的最多的就是 Vibe coding，可以说这个词席卷了整个编程界，Codex,Claude,Cursor 这些个 Agent 工具在日常的工作中已经离不开了。只要你能想到的所有在电脑上完成的工作都可以用这些 AI Agent 去完成，他们就是你的工作助手，帮你完成你手头上的很多工作。但是很反常的事情是，效率上去了，工作的时间却没有减少，因为公司也在疯狂裁人，也就意味着其他留下的人需要承担更多工作，AI 是提高了生产力，但是整个团队的作战效率并不一定会提升上去，因为产品研发的模式没有发生根本性的变化，无法做到直接对接客户，直接产出可交付的产品，当然这种情况研发人员的压力会非常大，直面客户，而且对研发人员的要求也会变高，就是前面提到的 E 型人才。
