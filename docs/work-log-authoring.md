# 更新工作记录

工作记录维护在 `work/`，英文版本放在 `en/work/`。`/work/` 和 `/en/work/` 会把各自语言的全部正文在同一页展开；每条记录的独立 `.html` 路由也会保留。

## 添加一条记录

创建两个同名文件，例如：

- `work/2026-10-21-map-interaction.md`
- `en/work/2026-10-21-map-interaction.md`

中英文使用相同文件名、日期与排序值，分别填写各自语言的内容：

```yaml
---
title: 这次工作在解决什么问题
date: '2026-10-21'
order: 1
area: 所属工作方向
description: 一句话概括，供“关于我”展示。
focus: 目前正在关注的问题或取舍。
tools:
  - React
  - 地图与空间数据
---
```

正文直接开始写段落，不重复写一级标题；条目标题由页面显示。需要小标题时从 `###` 开始，避免与同页各条记录的标题层级冲突。

## 日期与排序

`date` 是这条快照的记录日期，页面显示为“记录日期 / Recorded on”，不表示功能已完成或已上线。使用带引号的 `YYYY-MM-DD`，日期按 UTC 处理。

页面按记录日期从新到旧排列。同日多条记录用 `order` 决定顺序，数值越小越靠前；建议明确填写。同日期、同排序值的记录按路径排序。

## 持续更新

有新进展时新增一条带新记录日期的文件，保留旧记录，让读者能看到变化。旧记录可以纠正错别字或事实错误；工作状态发生变化时，在新记录里说明。

“关于我”自动读取同一份数据的最新 3 条，展示记录日期和摘要，并链接到完整工作记录页的对应条目。无需另改“关于我”的内容数组。中英文各自读取对应目录，请同步添加两个版本。
